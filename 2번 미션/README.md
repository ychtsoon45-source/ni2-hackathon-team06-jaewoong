# 2번 미션 · 라인가드 (LineGuard) v0.2

AI 물체인식 분류 · 불량 판정 · 생산통계 대시보드 시제품
6팀 해커트리오 (부천대학교 전자공학과·스마트팩토리전공) · 배정 기업 ㈜트윔

- 웹앱 주소 (GitHub Pages): https://ychtsoon45-source.github.io/ni2-hackathon-team06-jaewoong/2%EB%B2%88%20%EB%AF%B8%EC%85%98/
- 파일: `index.html` (HTML·CSS·JavaScript 한 파일, 빌드 없음, 로그인·결제·서버 없음)
- 분류 장치 예제: `lineguard_sorter.ino` (아두이노 UNO + 서보모터)

## 핵심 기능

1. **물체인식 분류 + 불량 판정**: Teachable Machine 모델로 웹캠(모바일은 후면 카메라) 또는 사진을 판정. 신뢰도가 기준값(기본 80%)보다 낮으면 "재검". 자동 판정 간격은 초 단위로 직접 입력(0 = 수동).
2. **생산통계 대시보드**: 총 처리·양품·불량·재검·불량률 자동 집계, 종류별 수량, 분 단위 불량률 추이, 판정 기록 표(작업일·시각·라인·로트), **CSV 내보내기**(엑셀용).
3. **분류 장치 연동**: 판정할 때마다 가상 분류기(컨베이어 + 양품/불량/재검함)에 표시하고, USB로 연결한 아두이노에 `OK`/`NG`/`RE` 신호를 보내 서보모터로 분류 (Web Serial, PC 크롬·엣지).

## 예제 모델

- 주조 임펠러 양품/불량 모델: https://teachablemachine.withgoogle.com/models/0bZ75DLgf/
- 화면의 "예제 모델" 버튼을 누르면 바로 불러와요.
- 학습: 양품 150장 + 불량 150장, 학습에 쓰지 않은 테스트 사진 20장 모두 정답.
- 학습 사진 출처: Kaggle "casting product image data for quality inspection" (PILOT TECHNOCAST, CC BY-NC-ND 4.0, 비상업용)

## 확인 방법

1. 웹앱 주소를 PC나 휴대폰 브라우저로 열기
2. **예제 모델** 버튼 → "사진으로 판정"에 임펠러 사진을 넣거나 웹캠에 비추기
3. 모델 없이 보려면 **데모 모드** → "판정 시작" (기록에 "샘플" 표시)
4. 기록을 엑셀로 받으려면 **CSV 내보내기**
5. 분류 장치: 아두이노에 `lineguard_sorter.ino` 업로드 → 서보 D9 연결 → 웹앱에서 **분류 장치 연결 (USB)** → 포트 선택 → "동작 테스트" 버튼으로 확인
