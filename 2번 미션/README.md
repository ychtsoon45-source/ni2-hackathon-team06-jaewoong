# 2번 미션 · 라인가드 (LineGuard)

AI 물체인식 분류 · 불량 판정 · 생산통계 대시보드 시제품
6팀 해커트리오 (부천대학교 전자공학과·스마트팩토리전공) · 배정 기업 ㈜트윔

- 웹앱 주소 (GitHub Pages): https://ychtsoon45-source.github.io/ni2-hackathon-team06-jaewoong/2%EB%B2%88%20%EB%AF%B8%EC%85%98/
- 파일: `2번 미션/index.html` (HTML·CSS·JavaScript 한 파일, 빌드 없음, 로그인·결제·서버 없음)

## 핵심 기능 (기획서 기능 1·2)

1. **물체인식 분류 + 불량 판정**: Teachable Machine 모델 URL을 불러와 웹캠(모바일은 후면 카메라) 또는 사진으로 부품 종류와 양품/불량을 판정. 신뢰도가 기준값(기본 80%)보다 낮으면 "재검". 수동 판정 또는 2/3/5초 자동 판정.
2. **생산통계 대시보드**: 총 처리·양품·불량·재검·불량률 자동 집계, 종류별 수량 막대그래프, 분 단위 불량률 추이, 최근 판정 기록 표.

## 확인 방법

1. 위 웹앱 주소를 PC나 휴대폰 브라우저로 열기 (또는 index.html을 내려받아 더블클릭)
2. 모델이 없으면 **"모델 없이 데모 모드"** → **"판정 시작"**: 가상 부품(볼트·너트·와셔)이 판정되고 대시보드가 바뀌는지 확인. 이 기록은 "샘플" 표시가 붙은 실습용 데이터예요.
3. 실제 판정: Teachable Machine(이미지 프로젝트)에서 클래스를 `볼트_양품`, `볼트_불량`, `배경`처럼 만들어 학습 → "모델 내보내기 → 업로드" 후 받은 링크를 넣고 **"모델 불러오기"** → **"판정 시작"** (카메라 권한 허용)
4. 웹캠이 없으면 "사진으로 테스트"에 이미지 파일을 넣어 판정

## 참고

- 기록은 브라우저(localStorage)에만 저장돼요. "기록 초기화"로 지울 수 있어요.
- 웹캠은 https 주소(GitHub Pages)나 내 PC 파일에서 동작해요.
- 아직 안 되는 부분: 실제 부품으로 학습한 모델 없음, CSV 내보내기, 분류 장치(서보/컨베이어) 연동
