## 2. 문제 정의와 프로젝트 기획

### 2-1. 문제 한 문장 (팀 결정: 사용자 = 라인 작업자)

> **소형 생산라인 작업자가 컨베이어 위 부품을 눈으로 분류하고 불량을 선별할 때 겪는 판정 편차와 기록 누락을, 웹캠 물체인식 자동 분류·불량 판정과 생산통계 자동 집계로 줄이는 웹앱**

### 2-2. 문제의 근거

| 근거 종류 | 상태 | 내용 |
|---|---|---|
| 자료 | 있음 | 트윔 공시·홈페이지·보도자료 (S1~S7): 검사 + 선별 + 이력관리 통합 수요, 생산실적 전산화 수요, AI 검사기 도입 장벽 |
| 관찰 | 아직 없음 → [가설] | 학교 스마트팩토리 실습 라인이나 현장 견학에서 분류·선별 작업 관찰 예정 |
| 인터뷰 | 아직 없음 → [가설] | 트윔 멘토 또는 현장 작업자에게 "판정 기준이 사람마다 다른가, 기록은 어떻게 하나" 질문 예정 |

### 2-3. 핵심 기능 (처음엔 2개만)

1. **물체인식 분류 + 불량 판정**: Teachable Machine 이미지 모델(웹캠)로 부품 종류(예: A/B/C)와 상태(양품/불량)를 인식하고, 신뢰도 기준값(예: 80%)보다 낮으면 "재검" 처리
2. **생산통계 대시보드**: 판정할 때마다 결과가 자동으로 쌓이고, 종류별 수량·불량률·시간대별 추이를 보여줌

나중에 할 것: 판정 결과로 분류 장치(서보/컨베이어) 제어, CSV 내보내기, 교대 리포트

### 2-4. 입력 화면

- 웹캠 실시간 영상 (가운데 큰 화면)
- Teachable Machine 모델 URL 입력칸 + "모델 불러오기" 버튼
- 불량 판정 기준값 슬라이더 (기본 80%)
- 라인/작업자/로트 번호 입력칸 (선택)
- "판정 시작/정지" 버튼, 수동 "판정" 버튼 (부품을 하나씩 올릴 때)

### 2-5. 결과 화면

- 판정 카드: 부품 종류, 양품/불량/재검 (초록/빨강/노랑), 신뢰도 %, 시각
- 생산통계 대시보드: 총 처리 수, 종류별 수량 막대그래프, 불량률 %, 시간대별 불량 추이 선그래프
- 최근 판정 기록 표 (시각, 종류, 판정, 신뢰도, 로트)
